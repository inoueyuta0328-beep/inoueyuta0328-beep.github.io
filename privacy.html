プライバシーポリシー

本ポリシーは、個人用ツール「切り抜きアップローダー」（以下「本ツール」）における情報の取り扱いを定めます。

1. 本ツールの性質

本ツールは運営者本人のみが使用する個人用のプログラムです。一般に公開しておらず、第三者にアカウント連携の機能を提供していません。したがって、運営者以外の利用者の個人情報を取得することはありません。

2. 取得する情報

本ツールは、運営者本人のGoogleアカウントについて、Google OAuth 2.0 により次の情報を取り扱います。

  • アクセストークンおよびリフレッシュトークン
  • 運営者が所有するYouTubeチャンネルの識別子およびチャンネル名
  • 運営者がアップロードした動画の識別子、タイトル、説明、公開範囲、字幕トラック

氏名、住所、電話番号、支払い情報、連絡先リスト、閲覧履歴などは取得しません。

3. 利用目的

取得した情報は、次の目的にのみ利用します。

  • 運営者自身が所有するYouTubeチャンネルへ動画をアップロードすること
  • アップロードした自身の動画のメタデータ、公開範囲、字幕トラックを設定・更新すること
  • アップロードした自身の動画の統計を取得し、制作の改善に用いること

これ以外の目的には利用しません。

4. 利用するGoogleの権限

  • https://www.googleapis.com/auth/youtube.upload
  • https://www.googleapis.com/auth/youtube
  • https://www.googleapis.com/auth/youtube.force-ssl

いずれも運営者自身のチャンネルに対してのみ使用し、他者のチャンネルやデータにはアクセスしません。

5. 保管と安全管理

認証トークンは運営者が管理する端末のローカルディスク上にのみ保存し、外部のサーバーへ送信・保管しません。Google API との通信はすべて HTTPS で行います。

6. 第三者への提供

取得した情報を第三者へ提供、販売、貸与、開示することはありません。広告、プロファイリング、機械学習モデルの学習には利用しません。

7. Google ユーザーデータの取り扱い

本ツールによる Google ユーザーデータの取得、利用、保管、共有は、Google API Services User Data Policy（限定的使用の要件を含む）に従います。

8. 保存期間と削除

認証トークンは、連携が不要になった時点で端末上から削除します。運営者は Google アカウントの権限設定 からいつでも本ツールのアクセスを取り消すことができます。取り消し後、本ツールは当該アカウントの情報へアクセスできなくなります。

9. 子どもの情報

本ツールは運営者本人のみが使用するもので、13歳未満の子どもから情報を取得することはありません。

10. 本ポリシーの変更

本ポリシーを変更する場合は、本ページを更新し、末尾の最終更新日を改めます。
